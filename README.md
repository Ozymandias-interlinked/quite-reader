# Quiet Reader

Upload a PDF, Word document, EPUB or text file and hear it read aloud. Page numbers, running headers, footnotes and links are skipped.

- Natural voices from [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) (Apache 2.0). They download once (about 90 MB) and run on your device.
- Works offline after the first visit. Install it to a phone or computer home screen.
- Your files are never uploaded. Everything runs in the browser.
